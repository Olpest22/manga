# Манга-сайт

Как добавить главу:

1. Создай папку `manga/имя-главы/` и закинь туда картинки страниц (001.jpg, 002.jpg, ...).
2. Впиши главу в `manga/manifest.json`:

```json
{
  "id": "имя-главы",
  "title": "Название главы",
  "pages": ["001.jpg", "002.jpg", "003.jpg"]
}
```

3. Закоммить и запушь — GitHub Pages подхватит сам.

## Публикация на GitHub Pages

1. Залей эту папку в репозиторий на GitHub.
2. Settings → Pages → Source → выбери ветку (обычно `main`) и папку `/root`.
3. Сайт появится по адресу `https://твой-юзернейм.github.io/имя-репо/`.

Порядок глав в manifest.json = порядок на сайте.
